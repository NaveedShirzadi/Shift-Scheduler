Restaurant Shift Scheduler

Project Overview:
The goal of this project is to help restaurant managers create employee schedules more efficiently while considering employee availability, job roles, staffing requirements, maximum working hours, and required breaks. The system aims to reduce the time managers spend creating schedules manually and help identify scheduling conflicts.

First CORE Feature — Version 0

Our first CORE feature is Build the Schedule.

For Sprint 1, our team is developing a simple Python program that:
- Reads employee information and staffing requirements from CSV files.
- Divides restaurant operating hours into 30-minute time blocks.
- Assigns available and qualified employees to required roles.
- Checks scheduling rules such as availability, maximum hours, overlapping shifts, and required breaks.
- Generates a valid one-day schedule or reports which roles and hours cannot be covered.
- Displays employee names, assigned roles, shift times, and breaks.
